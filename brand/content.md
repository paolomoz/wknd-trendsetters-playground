# Content Patterns

## Page Structure

Every page on WKND Trendsetters follows a consistent rhythm:

1. **Hero section** — Bold headline + subtitle + CTAs + imagery
2. **Content sections** — Alternating white/gray backgrounds for visual rhythm
3. **Social proof** — Testimonials, quotes, or community voices
4. **CTA section** — Full-width call-to-action with image overlay
5. **Footer** — Brand, social links, navigation columns

## Content Types

### Blog Posts

| Element | Convention |
|---|---|
| Title | Short, punchy, follows headline formulas from voice.md |
| Opening | Jump straight in — no "In this article, we will explore..." |
| Paragraphs | 2–4 sentences max. Break often. |
| Subheadings | Every 2–3 paragraphs. Action-oriented or intriguing. |
| Blockquotes | Use for standout quotes. Yellow left border. |
| Images | Minimum 2 per post. Rounded corners. Descriptive alt text. |
| CTA | End with a community-oriented CTA: "Ready to join?" or "Share your look" |
| Length | 600–1000 words. Concise over comprehensive. |
| Tone | Conversational. Write like you're texting a friend who asked for style advice. |

### Landing Pages

| Element | Convention |
|---|---|
| Hero headline | H1 in Syncopate uppercase. Max 8 words. |
| Subtitle | 1–2 sentences in Instrument Sans. Expands on the headline. |
| Section count | 4–6 sections per page. Don't overstuff. |
| Section headings | H2 in Syncopate uppercase. Max 6 words. |
| Section body | 1–3 paragraphs or a component (gallery, cards, tabs). |
| CTAs per page | 2–3 maximum. Primary + secondary in hero, one at the end. |

### Testimonials

| Element | Convention |
|---|---|
| Quote length | 1–2 sentences. Punchy, specific, personal. |
| Attribution | Full name + role/title (e.g., "Alex Rivera, Streetwear Enthusiast") |
| Avatar | Required. Rounded, 3rem size. |
| Tone | First person, enthusiastic, specific about what they love. |

## CTA Conventions

### Button Text
- Keep it under 3 words: "See trends", "Read more", "Join now"
- Use action verbs: See, Read, Join, Discover, Shop
- Never use "Click here" or "Learn more" (too generic)
- Never use "Submit" (too transactional)

### CTA Placement
- Hero: Primary + optional secondary button
- End of page: Full-width overlay CTA section
- Inline: Text buttons with arrow icon for "keep reading" actions
- Never more than 3 CTAs visible at once

## SEO & Meta

| Element | Convention |
|---|---|
| Title tag | `[Page Topic] — WKND Trendsetters` |
| Meta description | 1 sentence, includes target keyword, under 155 chars |
| Headings | One H1 per page. H2s for sections. H3s for subsections. |
| Image alt text | Descriptive, keyword-aware, not stuffed |
| URL slugs | Lowercase, hyphenated, descriptive (e.g., `/fashion-trends-young-adults`) |

## Content Calendar Categories

Content should rotate across these themes:

| Category | Frequency | Description |
|---|---|---|
| Trend spotting | Weekly | What's hot this week in casual, sporty, party styles |
| Style stories | Bi-weekly | Profile a persona or community member |
| How-to guides | Monthly | Practical style tips ("Layer like a pro") |
| Scene reports | Monthly | Coverage of events, concerts, festivals |
| Brand spotlights | Monthly | Highlight independent and emerging labels |
| Community features | Bi-weekly | UGC, reader submissions, "you wore it best" |
