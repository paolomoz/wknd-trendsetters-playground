CSS Enforcement Layer

Focus Ring System

:focus-visible applied globally to all interactive elements.

Ring width2px solid
Default color--color-black
Inverse color--color-white
Offset2px

Reduced Motion

prefers-reduced-motion: reduce media query disables all animations and transitions globally.

Applies animation-duration: 0.01ms, transition-duration: 0.01ms, and scroll-behavior: auto.

Skip Link

Hidden off-screen, slides in on focus. Targets #main-content.

Black background, white text, z-index 200. First focusable element in <body>.

Automated Validation

validate:a11y

Scans all .astro files for:

  • Images missing alt
  • SVGs missing aria-hidden
  • Buttons/links missing accessible names
  • Heading hierarchy violations
  • <nav> without aria-label
  • Presence of :focus-visible in CSS
  • Presence of prefers-reduced-motion

0 issues

validate:icons

Scans all .astro files for:

  • Non-standard viewBox dimensions
  • Hard-coded colors (not currentColor)
  • Missing aria-hidden on decorative SVGs
